# SIC Assembler Project

## Overview

This project implements **One-Pass and Two-Pass Assemblers in C** for the **SIC (Simplified Instructional Computer)** architecture.

The assemblers read a SIC assembly language program, process its instructions and symbols, and generate the corresponding **machine/object code**.

The project demonstrates the fundamental concepts of **assembler design, symbol table management, opcode processing, address assignment, forward references, and object code generation**.

# One-Pass Assembler

The One-Pass Assembler processes the source program in a **single pass**.

It:

* Reads the assembly source code
* Builds the symbol table
* Generates object code
* Handles forward references using a **fix-up mechanism**
* Uses the opcode table from `opcodes.txt`

### Compile

```bash
gcc 1PassAssembler.c -o onepass
```

### Run

```bash
./onepass
```

---

# Two-Pass Assembler

The Two-Pass Assembler processes the source program in two separate passes.

### Pass 1

Pass 1:

1. Reads the source program
2. Assigns addresses using the location counter
3. Builds the symbol table
4. Processes assembler directives such as `START`, `END`, `WORD`, `BYTE`, `RESW`, and `RESB`
5. Generates the intermediate file

The generated intermediate file is:

```text
intermediate.txt
```

### Pass 2

Pass 2:

1. Reads the intermediate file
2. Uses the symbol table generated during Pass 1
3. Converts mnemonics into machine opcodes
4. Resolves symbol addresses
5. Generates the final SIC object program

---

## Compile and Run Two-Pass Assembler

Compile:

```bash
gcc 2PassAssembler.c -o twopass
```

Run:

```bash
./twopass
```

## Input Files

### `sample_input.txt`

The assembler expects the source assembly program to be stored in:

```text
sample_input.txt
```

Example:

```text
COPY START 1000
FIRST STL RETADR
CLOOP JSUB RDREC
      LDA LENGTH
      COMP ZERO
      JEQ ENDFIL
      JSUB WRREC
      J CLOOP
ENDFIL LDA EOF
      STA BUFFER
      LDA THREE
      STA LENGTH
      JSUB WRREC
      LDL RETADR
      RSUB
EOF   BYTE C'EOF'
THREE WORD 3
ZERO  WORD 0
RETADR RESW 1
LENGTH RESW 1
BUFFER RESB 4096
      END FIRST
```

### `opcodes.txt`

The opcode table contains the SIC instruction mnemonic and its corresponding hexadecimal machine opcode.

Example:

```text
LDA 00
LDX 04
LDL 08
STA 0C
STX 10
STL 14
ADD 18
SUB 1C
MUL 20
DIV 24
COMP 28
TIX 2C
JEQ 30
JGT 34
JLT 38
J 3C
JSUB 48
RSUB 4C
LDCH 50
STCH 54
```

## Assumptions

* The assembly source program is stored in `sample_input.txt`.
* `sample_input.txt` must be present in the same directory from which the program is executed.
* `opcodes.txt` must also be present in the same directory.
* The assembler uses SIC instruction formats.
* The Two-Pass Assembler generates `intermediate.txt` automatically.
* Object code is displayed on the terminal.
* `intermediate.txt` does not need to be created manually.

## Working Flow

### One-Pass Assembler

```text
sample_input.txt
       │
       ▼
Read Source Program
       │
       ▼
Build Symbol Table
       │
       ▼
Generate Object Code
       │
       ▼
Resolve Forward References
       │
       ▼
Display Object Code
```

### Two-Pass Assembler

```text
             sample_input.txt
                    │
                    ▼
                 Pass 1
                    │
          ┌─────────┴─────────┐
          ▼                   ▼
    Symbol Table       intermediate.txt
          │                   │
          └─────────┬─────────┘
                    ▼
                 Pass 2
                    │
                    ▼
            Generate Object Code
                    │
                    ▼
             Display Output
```

* Two-Pass Assembly

## Output

The Two-Pass Assembler generates SIC object program records including:

* **Header Record (`H`)**
* **Text Record (`T`)**
* **End Record (`E`)**

Example format:

```text
H...
T...
T...
E...
```

The object code is printed directly to the terminal after successful assembly.

## How to Run the Project

Clone or download the project and navigate to its directory:

```bash
cd SIC-Assembler
```

### Run One-Pass Assembler

```bash
gcc 1PassAssembler.c -o onepass
./onepass
```

### Run Two-Pass Assembler

```bash
gcc 2PassAssembler.c -o twopass
./twopass
```

Make sure the following files are available in the same directory:

```text
1PassAssembler.c
2PassAssembler.c
opcodes.txt
sample_input.txt
```

The Two-Pass Assembler will generate:

```text
intermediate.txt
```

automatically.
